# منصة Chatlx - تطبيق الدردشة والتواصل الفوري 🚀

تطبيق ويب عصري ومتطور باسم **Chatlx** للدردشة المباشرة مع تسجيل الدخول بحساب **Google** وتصميم فاخر (Dark Glassmorphic Theme).

---

## 🌟 الميزات الرئيسية

1. **تسجيل الدخول باستخدام Google (Google Authentication)**:
   - زر Google Sign-In المعتمد بألوان وشعار Google الرسمي.
   - نافذة اختيار الحسابات (Google Account Chooser) مع حسابات تجريبية سريعة.
   - إمكانية إدخال أي حساب Google مخصص للمستخدم.
   - حفظ جلسة الدخول في الذاكرة المحلية (LocalStorage).

2. **قنوات وغرف المحادثة**:
   - قنوات افتراضية منظمة (`# عام`، `# تقنية وتطوير`، `# ألعاب وميديا`، `# استراحة`).
   - إمكانية إنشاء قنوات وغرف جديدة بسهولة عبر زر `+`.
   - عداد الرسائل غير المقروءة لكل غرفة.

3. **تجربة مراسلة متقدمة**:
   - إرسال النصوص الفورية وتنسيق فقاعات الرسائل.
   - إرفاق الصور ومشاركتها مع ميزة المعاينة قبل الإرسال (Image Upload & Preview).
   - تسجيل الملاحظات الصوتية (Voice Notes) مع مؤشر تفاعلي وصوت واقعي.
   - منتقي الرموز التعبيرية (Emoji Picker) التفاعلي.
   - التفاعل مع الرسائل (Reactions: ❤️, 👍, 🔥).
   - مؤشر الكتابة المباشر ("يكتب الآن...").
   - مؤثرات صوتية ناعمة عند إرسال واستقبال الرسائل عبر Web Audio API.

4. **مرونة التشغيل**:
   - **بدون سيرفر (Standalone)**: يمكنك فتح ملف `index.html` في أي متصفح مباشرة وسيعمل بكامل ميزاته مع ردود تفاعلية ومحاكاة ذكية.
   - **مع سيرفر Node.js**: يدعم خادم Express و Socket.io للربط المباشر بين أكثر من جهاز أو متصفح في الوقت الحقيقي.

---

## 💻 طرق تشغيل الموقع

### الطريقة الأولى: التشغيل المباشر والسريع
فقط افتح ملف `index.html` في متصفحك المفضل (Chrome, Edge, Firefox, Safari).

### الطريقة الثانية: تشغيل خادم Node.js و Socket.io (للمحادثة الحقيقية بين أجهزة متعددة)
افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع، ثم نفذ:

```bash
# تثبيت الحزم المطلوبة
npm install

# تشغيل الخادم
npm start
```
ثم افتح الرابط:
`http://localhost:3000`
